# Pronabelle Eco Salon

Single-page site for **Pronabelle Eco Salon** (Comayagua), based on the [luxury salon template](https://github.com/stellier7/luxury-salon-template).

Open `index.html` in a browser. No build step.

## Customize

Edit **`config.js`** for copy, colors, services, ritual steps, gallery URLs, products, and contact details.

Real salon photos live in `images/` and are referenced from `config.js` (hero, visit portrait, ritual strip, and gallery). Product packshots live in `images/products/` and power the homepage marquee plus `productos.html` (cart + WhatsApp).
